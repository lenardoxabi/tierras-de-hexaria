# Tierras de Hexaria

Juego de mesa 3D de colonización y comercio en un único HTML (Three.js). Tres ambientaciones (medieval, Hexaria Prime, Pompaelo), tres extensiones, partidas contra la máquina y multijugador P2P entre amigos. Disponible en castellano, euskera e inglés (se cambia en Ajustes).

Se sirve con GitHub Pages y se instala como aplicación (PWA): https://lenardoxabi.github.io/tierras-de-hexaria/
